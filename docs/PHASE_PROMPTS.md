# TintaPhoto 交辦範本

把對應的範本複製貼給 AI 即可。每次只交辦一個階段；驗收全部通過、你也實際操作確認過，再進下一階段。

建議每個階段開一個新的對話，避免前面的內容干擾。AI 會依 `CLAUDE.md` 的規則先讀 `docs/PROGRESS.md` 和 `docs/PLAN.md`。

---

## 通用範本

```
請開始 TintaPhoto 的【階段 N：階段名稱】。

1. 先依 CLAUDE.md 的「開始任何工作前」步驟，讀 docs/PROGRESS.md 與 docs/PLAN.md 的相關章節。
2. 用條列方式告訴我：你打算怎麼做、會新增或修改哪些檔案、有哪些地方 PLAN.md 沒寫清楚需要我決定。
3. 等我確認後再開始寫程式。
4. 完成後依 CLAUDE.md 第 10 節回報，並逐條對照 PLAN.md 第 9 節本階段的驗收項目與第 3.8 節設計品質驗收。
```

## 各階段範本

### 階段 0：專案骨架

```
請開始 TintaPhoto 的【階段 0：專案骨架】。

重點：
- 建立 PLAN.md 第 5 節的資料夾結構、pyproject.toml（含 dev 選用相依）、README、LICENSE（MIT，著作權人：【你的名字或 GitHub 帳號】）、THIRD_PARTY_NOTICES.md、licenses/、.gitignore
- 依第 3.5 節建立 ui/theme.py，並由它產生 QSS

- 設定檔讀寫、記住視窗位置
- 建立 docs/PROGRESS.md

這個階段還不需要真的開啟照片，按鈕可以先放著不接功能。

### 階段 1：開啟與顯示照片

```
請開始 TintaPhoto 的【階段 1：開啟與顯示照片】。

重點：
- core/decoder.py：RAW（rawpy）與 JPG 解碼（含 JPG 內嵌色彩描述檔）、EXIF 轉正、預覽代理圖（第 6 節步驟 1）
- core/color_management.py：色彩矩陣、Bradford 色適應、OkLCh，附單元測試
- 基礎色彩流程：過曝亮部中性化、色適應、基礎色調曲線、色域壓縮、輸出轉換（第 6 節步驟 4、5、9、11、12），讓所有滑桿為 0 時就接近相機 JPG
- 預覽區縮放與平移（第 3.3 節），包含以游標為中心的滾輪縮放
- 縮圖列、磁碟快取、預先解碼相鄰照片（第 4 節）
- 右側面板分頁架構、資訊分頁（第 3.9 節）
- 拖曳開啟

測試照片在 tests/samples/，請務必用真實的 ARW 測試。

先列出計畫給我確認，再開始寫。
```

- 預期結果：【…】
- 實際結果：【…】
- 照片：【檔名，或說明是哪種照片】

請先找出原因並說明，再提出修正方式，等我確認後再改。修好後補上能重現這個問題的測試。
```

請先說明你打算怎麼改、會不會影響 PLAN.md 第 3 節的設計規範。如果需要新增或修改 theme.py 的設計規範數值，請先列出來給我確認。
```

```
